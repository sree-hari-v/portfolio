## 🛠️ Built With

This project utilizes a clean, modern tech stack focused on performance, accessibility, and fluid responsiveness.

- **HTML5** for semantic, accessible page structure.
- **CSS3** for custom animations, CSS variables, and responsive Grid/Flexbox layouts.
- **JavaScript (ES6+)** for interactive elements such as typing animations, dynamic scroll reveals, and a mobile slide-out menu.
- **FontAwesome** for scalable vector icons.
- **Google Fonts** (Poppins & Fira Code) for modern, clean typography.

---

## ✨ Key Features

- **⚡ Fully Responsive:** Adapts flawlessly to mobile, tablet, and desktop viewports.
- **🎨 Dynamic UI/UX:** Features custom cursor effects, smooth scroll reveals, typing animations, and engaging hover transitions.
- **🌘 Modern Dark Theme:** Designed with a sophisticated dark aesthetic featuring a custom color palette (`#050505` background with vibrant red `#ff0000` accents) and modern glassmorphism elements.
- **📱 Mobile Navigation:** An intuitive, smooth slide-out menu tailored for smaller devices.
- **🚀 Highly Optimized:** Built with lightweight code and optimized assets (such as SVG favicons) for blazing fast load times.

## 💻 Local Setup

If you'd like to run this project locally to explore the code:

1. Clone the repository:
   ```bash
   git clone https://github.com/sree-hari-v/portfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your favorite web browser, or use an extension like VS Code's Live Server for hot reloading.
